# Utkarsh's Agent Configuration

* Never use em-dashes (—), use hyphens (-) instead.
* When writing a commit message, NEVER auto-add your agent-name as a co-author.
* When making technical decisions, do not give much weight to development cost. Instead, prefer quality, simplicity, robustness, scalability, and long term maintainability.

## Tools

* For any project involving Python, prefer to use uv environments unless the repo already is using some other package manager. In that other case, use pip.
