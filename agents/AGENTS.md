# Utkarsh's Agent Configuration

* Never use em-dashes (—), use hyphens (-) instead.
* When writing a commit message, NEVER auto-add your agent-name as a co-author.
* When making technical decisions, do not give much weight to development cost. Instead, prefer quality, simplicity, robustness, scalability, and long term maintainability.
* When building a repository from scratch, keep small, incremental commit messages. Whenever a new functionality is added, that needs its own separate commit message with the appropriate diffs. Prefer to commit as you are working.
* Have very descriptive commit messages and descriptions for fixes unless specified. Keep simple descriptions, using bullet points, if necessary (bullet points in commit descriptions are only required when the commit descriptions are to be made a little information sparse). 

## Tools

* For any project involving Python, prefer to use uv environments unless the repo already is using some other package manager. In that other case, use pip.
* When you need to search docs, use Context7.
